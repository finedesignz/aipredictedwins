## Summary

Generalized the swing trading engine into **strategy profiles**, added a self-learning
intraday **day-trade** bot (Bot D / `daytrade` profile), removed MiroFish/LLM from the live
trading path in favor of deterministic ATR exits, and closed the previously-open self-learning
loop so trade outcomes now drive entry vetoes and position sizing.

## Key Accomplishments

1. **`StrategyProfile` abstraction** — one engine, two presets (`SWING` reproduces prior
   behavior byte-for-byte so bots A/B are untouched; `DAYTRADE` = 5-min bars, 2-min scan, 1h
   HTF, ATR exits, 6h max-hold). Selected via `BOT_PROFILE` env.
2. **Deterministic ATR exits** replaced the MiroFish LLM exit advisor — ATR-scaled stop +
   trailing stop, with `hard_stop_pct` and `max_hold_hours` as absolute overrides. The live
   trading path now makes **zero LLM calls** (Claude-CLI auth plumbing removed).
3. **Self-learning loop closed** — `get_advice()` vetoes low-win-rate patterns and
   `confidence_adjustment` + `get_dynamic_thresholds()` scale Kelly sizing (static caps remain
   inviolate). Enriched with intraday dimensions (time-of-day, hold-minutes, volatility regime)
   and a **shadow→auto gate** (`LEARNING_SHADOW_UNTIL_TRADES`, default 30) that logs would-be
   actions until enough closed trades accrue.
4. **Fee/slippage pre-trade gate** — skips candidates whose expected move can't clear
   `2×taker_fee + slippage_buffer`, preventing intraday churn.
5. **Session-anchored VWAP + parameterized indicator periods** for correct intraday signals;
   `Signal` now carries `atr_value`.
6. **Bot D wiring + verification** — dashboard `KNOWN_BOTS`/attribution, fail-clear per-bot
   Alpaca keys, a real-loop learning integration test, and a deterministic 5-min
   signal-frequency backtest harness.

## Decisions

- Profile abstraction over a fork; SWING preset guarantees bots A/B never regress.
- 5-min/2-min cadence; no overnight holds (max-hold auto-close); shadow-first learning.
- MiroFish files retained on disk (Kalshi paused) but removed from the Alpaca import path.
- Migration `014_intraday_learning_dims.sql` is additive-only (`ADD COLUMN IF NOT EXISTS`).
