  def aggregate(rows: list[dict],
                min_sample: int = MIN_SAMPLE,

Input rows are psycopg3 dict_row dicts (src/db.py:29) as returned by db.get_resolved_trades:
  {bot_id, symbol, asset_class, side, status, pnl, fees, entry_ts, closed_at}
A plain dict fixture IS a row — that is what keeps this testable with zero DB.

Per-cell output fields (17-CONTEXT decision 2):
  bot_id (None when not in `key`), symbol (NORMALIZED; None when not in `key`), display, asset_class,
  trades, wins, losses, win_rate, realized_pnl, total_fees, avg_win, avg_loss, expectancy,
  best, worst, first_trade, last_trade, null_pnl, null_fees, sample

LOCKED definitions — each is pinned by a test; do not "improve" any of them:
| Rule          | Definition                                                        | Why |
|---------------|-------------------------------------------------------------------|-----|
| win           | `pnl > 0`                                                          | mirrors get_alpaca_accuracy (src/db.py:228) so the definition cannot drift |
| loss          | `pnl <= 0`, INCLUDING `pnl == 0.0`                                 | flat is not a win — `pnl` is already fee-net |
| trades        | rows with **non-NULL** `pnl`                                       | NULL is a defect, not a datum |
| realized_pnl  | `sum(pnl)` over non-NULL                                           | ALREADY net of fees (src/pnl.py:28) |
| total_fees    | `sum(fees)`, NULL fees -> 0.0 and +1 to `null_fees`                | drag DISCLOSURE only — NEVER `realized_pnl - total_fees` |
| avg_win       | `sum(pnl>0)/wins`, `0.0` when wins == 0                            | — |
| avg_loss      | `sum(pnl<=0)/losses`, `0.0` when losses == 0 — carried **NEGATIVE**| sign discipline makes the invariant hold |
| expectancy    | `win_rate*avg_win + (1-win_rate)*avg_loss`                         | **== realized_pnl / trades** — the load-bearing invariant |
| NULL pnl      | EXCLUDE from trades/wins/losses/realized_pnl/expectancy; `null_pnl += 1` | the anti-get_alpaca_accuracy rule (db.py:228,259 coerce with `or 0`) |
| sample        | `"sufficient"` if `trades >= min_sample` else `"insufficient"`      | cell is STILL EMITTED — hiding it hides a TRUMP-shaped leak |
| zero denoms   | every ratio `0.0`; `aggregate([]) == []`                            | no ZeroDivisionError, ever |

Reused (do NOT re-derive):
  src.universe.normalize(symbol) -> str   # src/universe.py:17 — the gate's canonicalizer. The group key.
