<objective>
Build the pure aggregator: `src/symbol_stats.py::aggregate`.

Purpose: Python decides (17-CONTEXT decision 1). Everything a reader of the report must be able to trust —
the win definition, the sign of `avg_loss`, the exclusion of NULL P&L, **the exclusion of sentinel zeros**,
**the gross-vs-net fee flags**, the sample guard, and the refusal to count a gate block as a loss — lives in
ONE pure function that unit tests can reach with plain-dict fixtures and zero DB.

**This plan is where plan-check's two FALSE premises get corrected.** SQL cannot see either defect:

- **`zero_pnl` (Rev-2 B1)** — `src/alpaca_orchestrator.py:167-176` writes `status="closed", pnl=0.0` for
  every externally-exited position (same shape at `src/bot_c/strategy.py:393`, `src/trend_strategy.py:172`
  when `entry_price == 0`). That row **passes the terminal-status filter**. Scoring `pnl == 0.0` as a loss —
  the original CONTEXT decision 2, now amended in place — would fabricate a losing record for **every
  externally-exited position**, and `null_pnl` would never see it (the value is `0.0`, not NULL). A genuine
  flat trade is **indistinguishable** from the sentinel, so **neither is scored**.
- **`gross_pnl_rows` / `null_fees` (Rev-2 B2 + R3-W1)** — `src/bot_c/strategy.py:393-395` and
  `src/trend_strategy.py:172-173` store a **GROSS** `pnl` and pass **no `fees`** arg, so `fees` lands NULL
  (`src/db.py:101-107,118`). `sum(pnl)` therefore mixes gross and net, and `total_fees` reads **$0 drag for
  exactly the bots whose P&L is overstated**. **NULL `fees` is the TELL.** Two counters, deliberately
  **distinct sets** so they can diverge and neither is redundant:
  - `null_fees` — **ALL** rows in the cell with `fees is None`, including `zero_pnl` and `null_pnl` rows.
    "How much of this cell has no fee data at all."
  - `gross_pnl_rows` — the **COUNTED SUBSET** (win/loss only). "How much of this cell's `realized_pnl` is
    un-fee-adjusted." `gross_pnl_rows <= null_fees`, always.

  **Never subtract fees.**

Output: src/symbol_stats.py (turns VALIDATION cases 1-17 GREEN, except the DB-gated 18 and the Plan-04 cases).

Per-cell output fields:

  trades, wins, losses, win_rate, realized_pnl, total_fees, avg_win, avg_loss, expectancy,

THE FOUR BUCKETS — a position-closed row lands in exactly ONE. Do not "improve" this:

| Bucket     | Condition       | Counted in trades/wins/losses/realized_pnl/expectancy? | Why |
|------------|-----------------|-------------------------------------------------------|-----|
| win        | `pnl > 0`       | YES (win)                                             | mirrors get_alpaca_accuracy (src/db.py:228) |
| loss       | `pnl < 0`       | YES (loss)                                            | — |
| **zero_pnl** | `pnl == 0.0`  | **NO**                                                | indistinguishable from the external-exit sentinel (alpaca_orchestrator.py:167-176). Scoring it as a loss fabricates a losing record on every externally-exited position. |
| **null_pnl** | `pnl is None` | **NO**                                                | a resolution defect; `db.py:228,259` coerce with `or 0` — this must NOT |

`null_pnl` and `zero_pnl` are DIFFERENT buckets with different causes. The `or 0` idiom cannot even
distinguish them — which is exactly the bug. Test with `row["pnl"] is None` / `row["pnl"] == 0.0`.

THE TWO FEE COUNTERS — DISTINCT SETS (R3-W1). If you implement them as the same predicate they can never
diverge and one of them is a lie:

| Counter | Population | Meaning |
|---------|-----------|---------|
| `null_fees` | **EVERY** row in the cell with `fees is None` — win, loss, **zero_pnl AND null_pnl** | how much of this cell has no fee data at all |
| `gross_pnl_rows` | the **COUNTED SUBSET** only (win/loss) with `fees is None` | how much of `realized_pnl` is un-fee-adjusted (their pnl is probably GROSS) |

Invariant: `gross_pnl_rows <= null_fees`. Case 7 asserts a fixture where `gross_pnl_rows < null_fees`.

| Rule          | Definition |
|---------------|------------|
| `trades`      | `wins + losses` (excludes zero_pnl AND null_pnl) |
| `realized_pnl`| `sum(pnl)` over counted rows — **NEVER minus total_fees** |
| `total_fees`  | `sum(fees)` over counted rows, NULL → contributes 0.0 — **INCOMPLETE drag disclosure** |
| `avg_win`     | `sum(pnl>0)/wins`, `0.0` when wins == 0 |
| `avg_loss`    | `sum(pnl<0)/losses`, `0.0` when losses == 0 — carried **NEGATIVE** |
| `expectancy`  | `win_rate*avg_win + (1-win_rate)*avg_loss` — **INVARIANT: == realized_pnl / trades** |
| `sample`      | `"sufficient"` if `trades >= min_sample` else `"insufficient"` — cell STILL EMITTED |
| zero denoms   | every ratio `0.0`; `aggregate([]) == []`; no ZeroDivisionError |

Reused (do NOT re-derive):
  src.universe.normalize(symbol) -> str   # src/universe.py:17 — the gate's canonicalizer. The group key.

Terminal set (copy from src/db.py:215 — cite it; this repo already has FOUR spellings, do not add a fifth):

  Everything else (rejected/canceled/cancelled/expired/open/submitted) is NOT a trade and is dropped
