<objective>
Build the anchored reconciliation window — the honest close for VERIFY-02.

Purpose: `reconcile_bot` compares two **cumulative-since-inception** quantities. The 395 historical
sentinel rows carry `pnl = 0.0` and contribute **exactly zero** to `trade_log_pnl`, while Alpaca's
`equity - starting_equity` already contains their true outcome. The delta is therefore
`≈ −(the sum of 395 unrecorded exits)` — **a fixed level offset**. Let any future trade be recorded
perfectly: it adds `x` to *both* sides and the offset is unchanged. **The offset is invariant under
all future correct behavior.** `abs(delta) <= $25` on the all-time window is unsatisfiable for A/B/C
forever, absent a write to those rows.

So the all-time check **keeps breaching**, is **relabelled `legacy: true`**, and its offset is
**surfaced** — never silenced, and never made green by widening a tolerance.

The honest window is anchored at `T0` = Phase-20 deploy, which is strictly **after** Phase 18's
sentinel-writer fix, so it contains **zero fabricated rows by construction**. And the anchor table is
a **forced move**: `AlpacaClient` has **no activities call and no portfolio-history call** — there is
literally no way to ask Alpaca what it realized since `T0`. It must be snapshotted.

Two moves would make a "green" result a lie, and both are structurally prevented here: **UPSERTing the
anchor** (which would re-anchor `T0` every run, emptying the window and making the check vacuously
green) and **widening the tolerance**. `ON CONFLICT DO NOTHING` and a pinned `$25` default are the
answers.

Output: migration `020` + the `src/db_schema.sql` mirror + the anchor read/write in `src/db.py` +
`reconcile_window` / `window_tolerance` / `ensure_anchor` in `src/reconciliation.py`.
</objective>
