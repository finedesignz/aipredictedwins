<objective>
Make the paper gate count trades.

Purpose: the 50-trade paper gate is one of the four hardcoded rules that stand between this system and
live money. It is currently satisfied by rows that **never became positions** — `submitted` entries,
`rejected` gate-blocks, canceled 0-fill orders. `settings.py:36` is a bare `COUNT(*)` with no status
filter and no P&L filter, and **no test asserted otherwise**, which is precisely why it shipped. It is
the same class of error as the `100_000.0 * len(bot_ids)` hardcode Phase 19 deleted two lines above it.

The fix needs **no new SQL**: `settings.py:43-49` already runs the canonical RESOLVED query for the win
rate. The count is `len(closed_rows)`.

**The gate will read WORSE.** That is the correct, intended outcome of making it honest, and it is not
to be tuned back. The gate is not being opened — it is being made real.

Output: `paper_trades_completed` = the RESOLVED count; `total_rows` still reported so the drop is
explainable. No risk rule, no target, and no threshold changes.
</objective>
