`trade_log_pnl` while Alpaca's `equity - starting_equity` already contains their true outcome. The
delta is therefore a **fixed level offset**, invariant under every future correct trade. `abs(delta)
<= $25` is unsatisfiable for A/B/C **forever**, absent a write to those 395 rows.

The honest close is an **anchored window** — and the anchor table is a **forced move**, not a
preference: `AlpacaClient` exposes **no activities and no portfolio-history call**, so there is
literally no way to ask Alpaca what it realized since `T0`. It must be snapshotted.

Two moves would let a "green" phase be a lie, and both are pinned here: **UPSERTing the anchor**
(re-anchoring `T0` every run → an empty window → a vacuously green check) and **widening the
tolerance**. Both are BANNED, and cases 24 and 29 are the pins.
