<interfaces>
Contract under test (created in Plan 02) — src/pnl.py:
  realized_pnl(side: str, entry_fill: float, exit_fill: float, qty: float, taker_fee: float) -> float
  - long (side not in {"sell","short"}): (exit_fill - entry_fill) * qty - fees
  - short (side in {"sell","short"}):    (entry_fill - exit_fill) * qty - fees
  - fees = (entry_fill*qty + exit_fill*qty) * taker_fee   (TAKER_FEE on BOTH legs)
  - SLIPPAGE_BUFFER is NEVER subtracted.
  Hand-computed golden values (fee 0.0025, qty 2): long 100->110 = 18.95; long 110->100 = -21.05;
  short 110->100 = 18.95; short 100->110 = -21.05; zero-fee long 100->110 = 20.00.

From src/fee_gate.py: TAKER_FEE, SLIPPAGE_BUFFER (module constants).

Test-double pattern to mirror (tests/test_order_resolution.py L31-68):
  FakeLogger(seed_rows) — in-memory rows dict; update_alpaca_trade(trade_id, status, exit_price=None,
    pnl=None) stores exit_price/pnl on the row. For this suite EXTEND the local copy with a
    `fees=None` kwarg that stores `row["fees"] = fees`.
  FakeAlpacaClient — scripts get_positions/get_latest_price/get_bars/close_position with
    _parse_order-shaped dicts (keys: status, order_id, filled_qty, filled_avg_price, ...).

Monitor under test — src/alpaca_orchestrator.py:
  PositionMonitor._check_positions() (L150-303). Close block L287-300 currently stores
  exit_price=current_price, pnl=trade_pnl (quote-based) and does NOT pass fees — so cases 6-8 fail RED.
  close_position(symbol) returns a _parse_order dict whose `filled_avg_price` is the real exit fill.
