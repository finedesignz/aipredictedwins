<objective>
Make the backtester model the live 4-rung deterministic exit ladder by replacing the flat
`-0.15/+0.30` barrier in `src/backtester/engine.py:89-105` with a call to the shared
`evaluate_exit` (Plan 01), fed a per-bar ATR computed from the engine's existing 50-bar OHLC
window. Add the five exit knobs to `PhaseConfig` + CLI (defaulted to StrategyProfile SWING values)
so the sweep can vary them alongside min_confluence/kelly_fraction.

Purpose: This is the fidelity fix — the harness measures the strategy the bot actually runs,
making the >=40% win-rate criterion continuous and falsifiable instead of a 2-valued flat barrier.
Output: Exit-knob-parameterized engine that fires the 4 rungs; integration tests.

LOCKED intra-bar convention (Research Pitfall 3, Open Question 2) — pessimistic / no look-ahead:
within a single 1H bar the hard stop and ATR fixed stop are evaluated against the ADVERSE extreme
(LONG: bar `low`; SHORT: bar `high`) BEFORE any favorable close/trailing check, so a stop that
could have triggered intra-bar is never skipped by a favorable close. Document this in a module
comment. Model the 4 DETERMINISTIC rungs only — no soft rung (Pitfall 1).
</objective>
